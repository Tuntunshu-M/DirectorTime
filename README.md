# 导演时间 / Director Time

SillyTavern 扩展。给角色配一个外置导演：不扮演角色、不替你说话，只在每次生成前把"这一场戏该怎么演"的指令放进 prompt，让 char 自己推动剧情。

你正常聊，插件在后台写分场剧本、判断推进到哪了、更新下一场的指令。它不插嘴，char 会照着演。

## 安装

### 方式一：在酒馆里用地址安装

1. 打开**扩展**面板
2. 点 **Install Extension**（安装扩展）
3. 粘贴仓库地址：

```
https://github.com/Tuntunshu-M/DirectorTime.git
```

4. 确认，等待安装完成
5. 刷新页面

### 方式二：手动安装

1. 下载本仓库（Code → Download ZIP）
2. 解压后把 `DirectorTime` 整个文件夹放进：
   ```
   SillyTavern/public/scripts/extensions/third-party/
   ```
3. 刷新酒馆页面

两种方式装完后，都在扩展列表里确认「导演时间」已启用。

## 界面

从酒馆的扩展菜单点「导演时间」打开。抬头五个图标是工具栏，下面是三个分类：

```
导演时间  DIRECTOR TIME        ▤ ≡ ⊙ ☀ ◢     ← 工具：世界书 / 提示词 / 设置 / 日夜 / 调试
● 启用中 · 第 6 场 / 共 8 场 · 本场第 3 楼     ← 常驻状态行，切分类也不变
──────────────────────────────────────────────
      场记      │     剧本     │   人物
```

| 分类 | 里面有什么 |
|---|---|
| **场记**（默认） | 总开关、本场（阶段 / 目标 / 状态 / 档位 / 注入 / 上次动作 / 伏笔 / 投机 / 累计）、生成与续写、待确认队列（L1 档位的结果要点「采用」才生效） |
| **剧本** | 阶段列表：↑↓ 重排、复制、删除、锁定、手改 goal 与走位（改过就自动锁定）；底部是伏笔区，可手动销账 |
| **人物** | 主角单选（多人卡）+ 该主演的八字段侧写；手改的字段自动锁定，AI 不覆盖 |

**抬头五个图标**（从设置里点「世界书 → 管理」也能进，返回键会退回设置）：

| 图标 | 打开 |
|---|---|
| 书 | 世界书：搜索书名 / 条目名、按书折叠、全选/全不选（只作用于当前筛选结果）、勾选条目并实时看 token 估算 |
| 三横 | 提示词 · 预设 · 清洗：破限预设（可选条目）、破限词四模式、模型特化预设、输出清洗规则 |
| 齿轮 | 设置：导演 API、世界书入口、偏好（剧情占比 / 导演强度 / 意愿权重 / 强制爱 / 投机 / **档位六项**）、**词库**、**调参**、安全（硬禁区）、副本迁移、版本更新 |
| 日 / 月 | 换配色：**夜间场记板** ⇄ **日间牛皮纸**（记在本机，立即生效） |
| 折线 | 调试面板：运行状态 + 本轮回放（注入全文 / 上次判定 / 模型原始返回 / 上次发给导演 API / 上一轮注入 / 角色回复原文与清洗后）+ **导演 API 日志**（时间 / 耗时 / tokens / 调用名 / 结果） |

面板上没有关闭按钮：点面板外的暗处、或按 Esc 关闭（有弹层时 Esc 先退弹层）。

## 配置

在酒馆的**扩展菜单**（魔杖图标）里点「导演时间」打开主面板，再点右上角「配置」填写。
也可以直接在浏览器控制台（F12）执行：

```js
DirectorTime.settingsPanel.show()
```

填三项：

| 字段 | 说明 |
|---|---|
| 端点 | 兼容 OpenAI Chat Completions 的地址，例如 `https://你的站子/v1` |
| 密钥 | API Key |
| 模型 | 模型名 |

这个 API 是**导演 API**，专门用来生成剧情，和酒馆跑角色回复的那个互不干扰，所以可以填便宜的模型。

点「测试连接」确认能用，保存。然后在主面板右上角打开**总开关**；没有剧本时点一次「生成剧本」。

「剧本轮数上限」默认 15：跑满这么多轮就自动清空剧本、重新开新戏（防无限膨胀，可在配置里改）。

## 使用

打开**总开关**、生成过剧本之后，正常跟角色聊天就行。每轮回复结束后，插件会在后台做三件事：

1. 判断这一场戏拍完没有
2. 推进到下一阶段
3. 把下一场的指令准备好 —— **你下一句话发出去时，它跟着进 prompt**

剧本会**自动续写**：待演阶段少于 2 条时就补新的，不会演到没戏。主面板上还有「重新生成剧本」（已有剧本时先确认）和「重新续写」（手动再写 2 条待演阶段）。

想看它干了什么：

```js
DirectorTime.debug.show()
```

调试面板默认展开「本轮回放」，能看到 user 说了什么、**本轮实际生效的注入内容**、char 回了什么、判定结果，以及下一轮将要注入的内容。托管版看不到后台也能排查。

两个容易看混的行，含义不同：

- **「已注册（下一轮用）」**：现在挂着的注入，**你下一次发消息时才会生效**
- **「本轮实际用的注入」**：生成**这条** reply 时真正生效的那份（是上一轮注册的）

所以它们可以是两个不同的东西（一个是空、一个有内容），不是打架。要是出现 **「⚠️ 注入断了」**，那才是真出问题：上一轮注册了内容、这一轮生成时却没了（多半被别的扩展覆盖了同一个 key，或中途换过聊天）—— 把这行发我。

还有一行 **「模型尾巴」**：识别 char 回复里**模型自己加的**收尾（`<thinking>` 块、"请选择接下来的剧情导向"、选项菜单这类）。这不是插件注入的，而是隐患 —— "请选择导向"等于把主导权交回给你，跟"char 主动推进"相反。插件只在 Debug 与控制台**报出来**，不擅自改 char 的回复；注入里会加一句反制（不要输出思考块、不要给选项菜单），要根治还得去角色预设那边关掉对应的规则。

另外几处：

- **「上一轮注入」**：上一次实际发出去的那份注入全文 + 当时投机命中没有（快速判断"是不是注入没跟上"）
- **「看原文 / 看清洗后」**（右上角按钮）：char 回复默认显示**清洗后**（判定实际吃到的就是这份），点一下可以切回原文对照
- **「流程说明」**（底部）：注册 → 跟随输入注入 → 判定 → 推进/熔断 → 投机，五行回忆整条链路
- **累计调用次数**：现在是真实计数（每次真发请求 +1），**跟聊天走、刷新页面不清零**

## 输出清洗（thinking 之类）

模型经常把 `<thinking>…</thinking>` 漏进正文，会污染判定。配置页 → 折叠区「输出清洗」：

- 内置两条规则：`<thinking>…</thinking>`、`<think>…</think>`（**未闭合、被截断到结尾的也能清掉**）
- 可以自己加正则（一行一条）；写错的正则会自动跳过，不影响主流程
- **只清洗导演时间自己消费的文本**（判定输入 + Debug 回放），**不改聊天记录**
- 关掉开关 → 判定看到原文

## 世界书

主面板点「世界书」：列出全部来源，支持搜索书名或条目，并显示启用状态（禁用 / 常驻）。右上角有**「全选 / 全不选」**（只作用于当前搜出来的条目，不会误勾看不见的）。

来源分组（T-433 起语义修正）：

| 分组 | 是什么 |
|---|---|
| **全局世界书（酒馆里全局启用）** | **只有**你在酒馆世界书面板里打了"全局"开关的那几本 —— 不是"酒馆里一共有多少本" |
| 其它世界书（未全局启用） | 剩下的书都在这里，一本不丢，照样能勾条目 |
| 角色主 / 角色附加 / 人格 / 聊天 / 角色卡内嵌 | 按绑定关系来的那几类 |

酒馆版本没把"全局启用"列表给扩展时，全局那组是空的并会写明原因，全部书落到「全部世界书」组里（想确认：控制台 `DirectorTime.ctx.getGlobalWorldInfoNames()`）。

**所有书默认折叠** —— 几百本书也不会一打开就铺满屏（以前"有启用条目就自动展开"）。展开/收起的状态会被记住：勾完条目、换个搜索词回来，还是你离开时的样子。

**按需读取（T-434）**：没读过的书只显示书名，旁边写着「点开即读取」—— 点一下才会读它（以前打开面板会把**所有**书读一遍，一百多本就是一百多次请求）。要点名的两条规则：

- **注入只读"有勾选的那本书"**：生成剧本时不会因为"有本书没读过"而漏掉你勾的条目
- **没读过的书只按书名搜**（它还没读，没条目可搜）；想按条目名搜遍全部，点工具栏的「读取全部 N 本」——那一下会把所有书读一遍，会慢

勾中的条目会进入导演 API 的 `{{world}}` 输入（最多 20 条）。展开「将发送给导演 API 的世界书文本」能看到实际发送的内容；Debug 面板的「上次发给导演 API」也能核对。

## 想让剧情往某个方向走（剧情走向）

「场记」页生成按钮上方有个**「剧情走向」**输入框，写你想让它怎么演，比如：

```
让他这一场挑明，但别太快和解；重点放在试探而不是表白
```

点「重新生成剧本」时会把它当成"用户的想法"一起交给导演（角色回复端不受影响）。改完不用另存，直接点生成即可；内容存在设置里，关掉面板再打开还在。

## 主角 / 攻略对象（多人卡 + 自选 NPC）

「人物」页顶部那块：

- **自动识别**：列出你酒馆里的角色卡，勾上谁，导演就把阶段写成"谁的戏"（阶段会标 `actorId`）
- **自选**：手填名字加人（**想攻略没有角色卡的 NPC** 就用这个），加进来后能单独移除
- 没勾的角色**不会拿到注入**（T-412 的规则）；如果**当前生成者不在名单里**，面板会红字提醒你

```js
DirectorTime.cast.candidates()   // 酒馆里识别到的角色卡
DirectorTime.cast.get()          // 当前名单（手填的带 manual: true）
```

## 人物侧写

配置页底部展开「人物侧写」：八个字段（核心欲望 / 恐惧 / 说话方式 / 对 user 的态度 / 处理冲突的方式 / 主动程度 / 亲密表达 / 禁忌）。

点「重新生成侧写」，导演 API 会按角色卡 + 世界书 + 近期对话写这八项。**手改过的字段会锁定，AI 不再覆盖**；点字段旁的「解锁」或「全部解锁」能还给它。

侧写存在角色卡上（换聊天不用重生成，换角色才需要），并同时作用于两端：剧情生成的输入，以及每轮注入指令里的「角色动机层」。

## 更新

面板底部有两个按钮：**「检查更新」** 和 **「更新插件」**。

- **检查更新**：真去比本地与远程的版本号，结果写在面板上（不是控制台）——
  有新版本会写「有新版本 vX（当前 vY）→ 点「更新插件」」，没有就写「已是最新版（vY）」；
  连不上 GitHub / 扩展没声明仓库地址时**如实说查不到**，绝不会假装"已是最新"
- **更新插件**：让酒馆把扩展拉到最新，成功后**页面自动刷新**，不用再跑去酒馆的「扩展」面板
- 更新走的是酒馆自己的接口（`/api/extensions/update`），**不碰你的数据** —— 剧本、进度、侧写、世界书勾选、设置都不会动
- 酒馆各版本把扩展放在不同目录，插件会**逐条试**并记住成功的那条；失败时**不假装成功**，而是明确告诉你去「扩展」面板手动更新
- 就算你不点：酒馆自己的 Update 换了文件之后，插件会在 15 秒内发现版本变化并自动刷新页面（刷新前先记下新版本，不会来回刷）
- **自动查 GitHub**（T-430）：打开酒馆约 3 秒后会自己查一次远程版本；有新版本就在消息区提示一次（**同一个版本只提示一次**），并在「设置 → 底部」常驻显示「有新版本 vX」。之后每 10 分钟复查一次（本地那份的 15 秒轮询只负责"文件变了自动刷新"，不给 GitHub 添流量）

万一按钮报「认不出插件目录」（极少数酒馆版本），把扩展目录名告诉它一次，以后就一直用这条：

```js
// 目录名 = 你安装时用的文件夹名（酒馆里「扩展」面板上能看到）
DirectorTime.store.saveSettings({ updatePath: { name: 'third-party/你的扩展目录名', global: true } })
```

## 剧本编辑器（面板右上角「剧本」）

AI 生成的剧本随时能改，改完立刻生效：

- **大纲**：标题 / 主线目标 / 一句话前提
- **阶段**：加一阶段、在其后插入、复制、删除、↑↓ 调顺序；每阶段的标题 / 本场目标 / 主要活动 / 达成条件 / 反意图 / 走位（一行一条）/ 附注都能手填
- **附注**会作为「本场附注」进注入 —— 你写给自己看的提醒，也可以直接当指挥
- **锁定**：勾上之后 AI 不再改这一场（重写走位、一致性自检、重生成都跳过它）；**你自己手改永远生效**
- **从当前阶段往后截断重生成**：后面演偏了，砍掉重写一批新的
- **快照**：导出 JSON 存下来、导入回去（往返无损，含阶段 id / 状态 / 进度），也可以拿别人的剧本导入
- **伏笔**：列出待回收的伏笔，逐条点「标记已回收」

## 生成时会看你的 persona（用户人设）

T-435 起，**剧本生成 / 续写 / 侧写 / 主动性**四处请求都会带上你的 persona（酒馆里你自己那份人设）：

```
user 的人设（必须尊重：不要写出他明确反感 / 忌讳 / 过敏的东西，也不要替他做决定）：
名字：小雨
人设：讨厌薄荷，怕吵
```

这条是从"用户在 persona 里写了讨厌薄荷，模型还让 char 送薄荷"来的。读不到 persona 的酒馆版本**不会瞎编**（那段整个不出现，请求与以前逐字一致）。想核对：

```js
DirectorTime.userPersonaText()   // 空串 = 没读到（把这个结果发我）
```

## 模型特化预设（按模型反向矫正）

不同模型的毛病是**相反**的，所以给两套，二选一：

| 选哪套 | 治什么 | 做什么 |
|---|---|---|
| **Claude · 主动性与情感表达** | 太谨慎、爱写被动等待 | 推它主动：禁被动句式、这一轮必须有具体动作、情绪写出来不写结论、僵局自己打破 |
| **Gemini · 角色塑造红线** | 容易极端化、模板化 | 拉回边界：禁控制狂 / 病娇套路，占有欲必须有心理与动机 |

两套都自带 **6 条生成前自检**，都只注入到**导演请求**（也就是剧情生成那一路）：

- **它管的是剧本，不管角色回复** —— 确保生成出来的剧情不越界 / 不写成被动等待
- 进请求的位置：`[破限词] → [模型特化预设] → [导演指令]`
- 默认关闭；不开启时一个字都不注入；两套各存自己的文本，改一套不会串到另一套
- 文本可以随便改（改完用你自己的那份），点「恢复内置」回到出厂
- 改完立刻生效：Debug 的「上次发给导演 API」能直接看到它排在最前面

配置页 → 折叠区「模型特化预设」。控制台等价写法：

```js
DirectorTime.modelPreset.set({ kind: 'claude' })   // off / claude / gemini
DirectorTime.modelPreset.set({ custom: '我自己的版本' })  // 写进当前选的那套
```

## 偏好（导演强度 / 投机预生成）

配置页 → 折叠区「偏好」。

**导演强度**：三档，只改**注入文案的语气**，判定逻辑、状态机、熔断、用户意愿矩阵一律不受影响。

| 档 | 效果 |
|---|---|
| **克制** | 强祈使句换成提议语气（"你要主动做的一件事" → "可以试着做的一件事"、"不要等 user 开口" → "如果气氛合适，你可以试着推进"）；内敛 / 冷淡角色不会被写成热情外放 |
| **标准**（默认） | 现状，一个字都不变 |
| **强势** | 标准档 + 一句"由你主导节奏，不必等 user 回应每一步" |

配合「模型特化预设」里那句恒开的人设尊重：**GEN_OUTLINE / EXTEND_OUTLINE / GEN_PROFILE 都会要求"推进方式必须符合角色既有性格"** —— 剧情推进和人设不冲突。

**投机预生成**：默认开。每轮多一次预判调用（猜你下一句的意图），命中才用得上针对性注入，猜不中静默丢弃。关掉后本轮起不再发投机调用。

```js
DirectorTime.intensity.set('restrained')   // 克制 / standard / assertive
DirectorTime.speculate.setEnabled(false)   // 关掉投机
DirectorTime.speculate.status()            // 开关 + 命中率
```

## 每轮花几次 API 调用

判定是**一次调用拿三段**（态度 + 推进点 + 投机预生成），站子按次计费的话这点很关键：

- 本地规则能定态度（说"好""不要"这类强词）→ **零调用**，只单独跑一次推进点判定
- 规则定不了 → **1 次合并调用**（原来要 2~3 次）
- 关掉投机 → 合并调用里不带投机段，也不再多发一次

Debug 的「本轮回放 → 判定来源」会写明这一轮是「本地规则（零调用）」还是「合并调用（1 次拿三段）」，以及三段各自解析到了没有（哪段坏掉就在这儿看得见）。

## 档位 / 词库 / 调参（设置里三个折叠区）

**档位**（设置 → 偏好）：六个功能点各自可设 **L0 全手动 / L1 待确认 / L2 全自动**。

| 档位 | 意思 |
|---|---|
| L0 | 那一步完全不跑（例：推进点判定关掉 → 全靠你手动切场） |
| L1 | 照跑，但结果先进「场记」页的**待确认**队列，点「采用」才生效 |
| L2 | 直接生效（默认：大纲 / 阶段重生成 / 侧写是 L1，三个判定是 L2） |

**词库**（设置 → 词库）：规则引擎用来**本地**判断你的态度 —— 判得准就一次 API 都不发。四本：

- 强词（直接表态）、弱词（含糊）、否定（反转）、转向（聊别的）
- 一行一条；强词 / 弱词可写 `词 = 立场`（接受 / 拒绝 / 犹豫 / 转向，或 accept / reject / hesitate / redirect）
- **清空某一本 = 这一类不判，老实交给 LLM**（不会硬猜）；「恢复默认词库」一键还原
- 立场认不出的行会被跳过并当场告诉你，不静默

**调参**（设置 → 调参）：默认值就能用，不懂别动。

| 参数 | 默认 | 一句话 |
|---|---|---|
| 每场楼层 min ~ max | 3 ~ 8 | 至少演几楼才允许切场；聊满 max 楼无论如何强制换场 |
| 轮数上限 | 15 | 跑满这么多轮就提示并清空剧本 |
| 置信阈值 | 0.7 | 判定把握低于它一律按"接受"放行 —— 调高更严，也更容易卡住 |
| 卡住阈值 | 3 | 连续几轮没推进就强制跳场（防死锁） |
| 世界书条数上限 | 20 | 勾选再多也只把最相关的这么多条进 prompt |
| 一致性自检 | 开 | 写完剧本再花一次调用查前后矛盾；关掉省一次 |

## 更多开关

配置页里有折叠区的直接点；下面这些命令在控制台改也一样生效（改完立刻生效、重启不丢）：

```js
// 三级自动化档位：大纲 / 阶段重生成 / 侧写 / 立场判定 / 推进点判定 / 一致性自检
// （配置页有下拉，直接点也行）
DirectorTime.automation.set('outline', 'L2')   // L0 全手动 / L1 待确认 / L2 全自动

// L1 的产物都在「运行状态 → 待确认」里，面板上点「采用」才生效
DirectorTime.queue.list()                      // 看还有哪些等着确认
DirectorTime.queue.approve('pr_xxx')           // 确认后才生效

// 剧情占比（三条线联动，和恒为 100）—— 配置页也有入口，拖一条另两条自动配平
DirectorTime.tone.set('daily', 60)

// 硬禁区：命中即停，优先于侧写禁忌
DirectorTime.store.saveSettings({ hardLimits: ['自杀', '自残'] })

// 破限词：off / preset（跟随酒馆预设）/ custom / append —— 配置页也有下拉，选「跟随酒馆预设」才会真的用上预设
DirectorTime.breakFilter.set({ mode: 'custom', custom: '……' })

// 破限预设：直接选一个酒馆里已经调好的预设当破限词（只读，不改编它）
// 配置页的「预设」折叠区可以勾选：只取勾中的那几条（一个不勾 = 用全部启用的条目）
DirectorTime.presets.list()            // 列出酒馆预设
DirectorTime.presets.select('预设名')   // 选中（配合 breakFilter 的 preset / append 模式）
DirectorTime.presets.entries()         // 看这个预设有哪些条目
DirectorTime.presets.selectEntries([0, 2]) // 只取第 1、3 条
DirectorTime.presets.probe()           // 列不出来时，把这行结果发我 —— 它显示这个酒馆到底暴露了什么

// 主角（多人卡，可多选）—— 配置页也有入口
DirectorTime.cast.set([{ name: '爱丽丝' }, { name: '鲍勃' }])

// 伏笔销账在「剧本」页点；副本导出导入在配置页点
DirectorTime.foreshadows.list()
const copy = DirectorTime.copy.export()        // 存成 JSON 就能搬走
await DirectorTime.copy.import(copy)           // 导入前会给你看概览与警告
```

投机执行（默认开）每轮多花一次导演 API 调用，换成"下一轮零延迟"；关掉：`DirectorTime.store.saveSettings({ speculation: false })`。

## 态度词库（规则引擎）

判断你的态度**先走本地规则**（免费、即时），规则拿不准才去问导演 API。所以像「好」「我不要」这种明确表态，不会产生任何 API 调用。

四个词库都能改：**强词**（命中就定，如 好 / 不要）、**弱词**（只能加权，如 嗯 / 也许）、**否定词**（反转其后的词：不 / 没）、**转向词**（天气 / 换个话题，以及 不过 / 但是 这类转折）。

词库编辑还没有界面入口，需要时在控制台改，改完立刻生效、重启仍在：

```js
DirectorTime.rules.get()      // 看当前词库
DirectorTime.rules.reset()    // 恢复默认

// 加词：把「不想说」也算拒绝
const r = DirectorTime.rules.get()
DirectorTime.rules.set({ ...r, strong: [...r.strong, { word: '不想说', stance: 'reject' }] })
```

`stance` 只填 `accept` / `reject` / `hesitate`；否定词和转向词只填词本身（`['不','没']`）。词库清空后规则引擎什么都不判，全部交给导演 API，不影响使用。

## 主动性

不显式要求主动性，模型会退化成「一问一答的客服」。所以每轮注入指令里都带一句 **「如果冷场，你就……」**——而且这句话不是模板：

- 它由**人物侧写**推导（写剧本时一并生成，比如「看海」这个欲望 → 冷场时他会不会主动提起出海）
- 没有侧写就不写，退回通用句 —— 凭空编角色行为等于造人设，不如不做
- **侧写更新后，旧的那句立即失效**，当前这场戏会自动按新侧写重生成一次（同一版侧写只试一次；失败就先用通用句，不会注入过期内容）

想换掉某场戏的主动性，改侧写再重生成即可；什么都不用配。

## 主目标与楼层节奏

剧本有一个**主目标**（`objective`），所有阶段都服务于它；自动续写时也会带上，不会续着续着跑偏。

每场戏有**楼层节奏**（默认 3~8 楼）：够 3 楼才切场，聊到 8 楼强制切场。达成得早的场次会进入「收尾」——char 顺势引出下一件事，不重复问、也不卡住；`min` 是节奏下限，**不会压着不推进**（第 1 楼就达成，第 1 楼就收尾）。

这两项目前没有界面入口，需要时在控制台改：

```js
DirectorTime.store.saveSettings({ objective: '你的主目标', pacing: { min: 3, max: 8 } })
```

## 用户意愿与硬禁区

这两项在**配置页**有入口：

- **用户意愿**：一条 0~100 的权重 + 「强制爱」开关（见下节）
- **硬禁区**：一行一条，剧情里触及这些内容 → 清空注入、本轮终止（优先于侧写禁忌，强制爱也覆盖不了）

配置页里这些也都有入口：预设与破限词（同一个区，带**预设内容预览**）、模型特化预设、剧情占比（三条线联动配平，**可以锁住某条线**，锁了就只配平其余两条）、主角（和人物侧写同一个区）、副本导出导入。

## 用户意愿（让步程度）

`will` 决定「你反对时 char 怎么反应」，默认 80（user 优先）：

- **0~33 剧情优先** —— char 会坚持，你反对也不轻易改道
- **34~66 平衡**
- **67~100 user 优先** —— char 会让步；你反对得越明确，越可能直接作废本场、重生成后续

你不需要配合剧本：明确反对时 char 会照着你的意思改道；说无关的话题时（高意愿档）剧情会跟着你暂停，不硬拉回来。卡住超过 3 轮自动放行，不会死锁。

**强制爱**（默认关闭）：开了之后，你口头拒绝也不让步 —— char 继续推进本场，不会改道、不会作废剧本。
它只管"口头拒绝"这一种情况：触及硬禁区、关掉总开关、犹豫 / 无关 / 转向，一律照常处理。
（体验上：怎么反抗，char 都会带着你走。卡住超过 3 轮仍然会靠熔断推进，不会原地打转。）

```js
DirectorTime.store.saveSettings({ forceAffection: true })
```

同样没有界面入口，控制台改（也可按阶段单独覆盖 `stage.will`）：

```js
DirectorTime.store.saveSettings({ will: 50 })
```

## 常见问题

**扩展菜单里没有「导演时间」入口**
控制台里看有没有 `[导演时间] 已加载` 和 `[导演时间] 菜单入口已挂载`。前者没有=扩展没加载成功，检查文件夹位置和名字；后者没有=酒馆还没渲染出菜单，等 2 秒会自动重挂。

**更新了插件，界面还是旧的**
酒馆里点 Update / 覆盖扩展文件后**不用手动刷新**：插件每 15 秒检查一次 `manifest.json`，发现版本变化会提示并自动刷新（首次安装那次只记录版本、不刷新）。

**注入一直是空的**
配置里「剧情注入」勾了吗？调试面板里 `本轮注入` 显示什么？如果是空的，去看「模型原始返回」—— 多半是 API 调用失败了。

**剧情不推进**
看调试面板的「上次判定」：status 和 confidence 分别是多少。confidence 低于阈值时插件会主动放行（宁可跳一步也不卡住），所以卡住通常说明判定根本没跑起来。

**切了聊天还在用上一个剧本**
不应该。切聊天会自动重载状态并清空注入。如果发生了，把调试面板导出的 JSON 发来：

```js
DirectorTime.debug.exportJson()
```
