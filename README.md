# 导演时间 / Director Time

SillyTavern 扩展。给角色配一个**外置导演**：不扮演角色、不替你说话，只在每次生成前把"这一场戏该怎么演"的指令放进 prompt，让 char 自己推动剧情。

> 说人话：你正常聊，插件在后台写分场剧本、判断推进到哪了、更新下一场的指令。它不插嘴，char 会照着演。

## 它不做什么

- 不以你的身份发消息
- 不修改聊天记录
- 不在对话里显示任何注入内容（只在调试面板可见）

## 安装

1. 把整个 `DirectorTime` 文件夹复制到：
   ```
   SillyTavern/public/scripts/extensions/third-party/DirectorTime/
   ```
2. 刷新酒馆页面
3. 在扩展管理里确认「导演时间」已启用

## 配置

刷新后配置面板会自动弹出。填三项：

| 字段 | 说明 |
|---|---|
| 端点 | 兼容 OpenAI Chat Completions 的地址，例如 `https://你的站子/v1` |
| 密钥 | API Key |
| 模型 | 模型名 |

这个 API 是**导演 API**，专门用来生成剧情（不是酒馆跑角色回复的那个）。两者互不干扰，所以可以填便宜的模型。

勾上「启用插件」「剧情注入」，保存。

## 调试

看不到后台也能排查——调试面板默认展开「本轮回放」：

```js
DirectorTime.debug.show()
```

能看到：user 说了什么、**本轮实际生效的注入全文**、char 回了什么、判定结果，以及下一轮将要注入的内容。
